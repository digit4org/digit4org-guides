# Digit 4 ORG – Guides for NGO Digitalization

**Digit 4 ORG** is a nonprofit initiative by **Asociatia D'Apetresii** (Oradea, Romania) that helps NGOs go through their digital transformation.

Many small nonprofits don't know about, or don't know how to use, the free digital tools and technology grants available to them. This repository collects free, open-source, step-by-step guides that help NGOs find the right tools, apply for nonprofit programs, and use them in their daily work.

## What you'll find here

- **Application guides** – how to apply for tech programs for nonprofits (GitHub for Nonprofits, Microsoft, Google and others)
- **Implementation guides** – how to set up and use these tools in an NGO
- **Templates** – reusable texts and checklists for applications and onboarding
- **Training materials** – resources for workshops with NGO staff and volunteers

## Project status

🚧 The project is at an early stage. The first guides are being written, and the website [digit4.org](https://digit4.org) is coming soon.

## 🇷🇴 Despre proiect

**Digit 4 ORG** este o inițiativă a **Asociației D'Apetresii** din Oradea, care sprijină ONG-urile în procesul de digitalizare. Aici publicăm ghiduri gratuite, pas cu pas, despre cum pot ONG-urile să obțină și să folosească instrumentele digitale oferite gratuit organizațiilor nonprofit.
